# ILYICHEV / SRE workstation

Резюме-паспорт SRE / DevOps / Platform-инженера Льва Ильичёва в виде красного CRT-монитора. Данные реальные, кроме служебной стилизации терминала. Публикуется как статика (GitHub Pages).

## Запуск

Требуется Node.js 18+. Зависимостей нет.

```sh
cd /Users/lev/crt-devsecops
npm run dev
```

Открыть http://localhost:5173. Для другого порта: `PORT=8080 npm run dev`.

## Управление

- `1`–`5`: единственный способ переключения разделов.
- `Tab` / `Shift+Tab`: фокус на действиях (копирование контакта, звук, питание).
- `Space` / `Enter`: действие выбранного элемента.
- `Space` при выключенном экране: загрузка системы.
- Физические кнопки SOUND и питания также доступны мышью. На телефоне нужна внешняя или доступная системная клавиатура.
- Стрелки, колесо и жесты не листают содержимое монитора. Каждый раздел целиком вписывается в экран; размер пересчитывается после загрузки шрифтов и изменения окна.

Компьютер изначально выключен. `Space` запускает BIOS со звуком; Web Audio синтезирует писк без аудиофайлов. SOUND позволяет отключить звук. Учитывается системная настройка уменьшения движения.

SVG-фильтр `feDisplacementMap` искривляет весь слой изображения: текст, линии, схему, загрузку и полосы развёртки. Карта обратного бочкообразного искажения рассчитывается в `updateCurvature()` в `app.js`; параметр `bend` задаёт силу выпуклости. Физические блики стекла расположены поверх этого слоя.

## Персонализация и публикация

Тексты, проекты, показатели, имя и контакт находятся в `index.html`. Адрес для копирования — также в `app.js`. Цвета и геометрия монитора — в `style.css`. Шрифты IBM Plex Mono и Oswald загружаются из Google Fonts; без сети используются системные шрифты.

На любой статический хостинг достаточно загрузить `index.html`, `style.css`, `app.js`. `server.mjs` нужен только для локального просмотра. Секретов, API-ключей, аналитики и серверных зависимостей нет. Изображение монитора сделано на CSS, схема инфраструктуры — на SVG.

Проверка синтаксиса: `npm run check`.
